# Nærme v3

Dette er en PWA-prototype for iPhone.

## Viktig
1. Last opp ALLE filene i denne mappen til GitHub Pages.
2. Overskriv de gamle filene.
3. Vent til GitHub Pages er publisert.
4. Åpne siden i Safari.
5. Velg Del → Legg til på Hjem-skjermen.
6. Start Nærme fra ikonet.
7. Trykk «Test varsel» første gang og tillat varsler.
8. Tillat posisjon «Når appen brukes».

## Begrensning
Denne PWA-en kan overvåke posisjonen mens appen er aktiv. iPhone-webapper har ikke samme bakgrunns-geofencing som en native iOS-app. For en produksjonsversjon som skal varsle pålitelig når appen er lukket, bør Nærme bygges som en native iPhone-app med Core Location.
